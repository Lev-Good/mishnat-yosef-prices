# מערכת AI אוטונומית לעדכון מחירי סופרמרקטים שבועי

מערכת זו אחראית על שליפה, בדיקה, אימות ועדכון שבועי של מחירי מוצרי הצריכה והמזון ברשתות השיווק בישראל עבור תוסף **"מוסיף למשנת"**.

---

## 🌟 איך המערכת עובדת בענן (GitHub Actions)?

1. **תזמון שבועי:** המערכת רצה אוטומטית בכל יום ראשון בשעה 07:00 בבוקר (שעון ישראל).
2. **שליפת מחירי אמת עדכניים:** ה-Pipeline שולח שאילתות אצווה ל-**Gemini 3.8 Flash** המחובר ל-**Google Search Grounding**.
3. **רשתות נבדקות:**
   * **אושר עד** (`osherAd`) - סניפי ירושלים/בני ברק
   * **רמי לוי** (`ramiLevy`) - מחלקות מהדרין / סניפי מהדרין
   * **יש חסד** (`yeshHesed`) - סניפי ירושלים/בני ברק
   * **נטו חיסכון** (`netoChisachon`) - סניפי אלעד/בני ברק/ירושלים
4. **עקרונות איכות ודיוק (Zero Guessing):**
   * **אין הערכות:** רשת שאין עבורה מחיר מאומת מקבלת `null`.
   * **ירקות ופירות:** נבדקים אך ורק מחירי מהדרין (בד"ץ / רובין / קהילות) בסניפי הערים החרדיות לפי 1 ק"ג.
   * **בקרת משקלים (Unit Parser):** סינון קשיח המונע השוואה שגויה בין גדלים (לדוגמה 70 גרם מול 150 גרם).
   * **בקרת שפיות מחיר:** חסימת חריגות קיצוניות (מתחת ל-40% או מעל 220% מהמחיר המקורי).
5. **עדכון אוטומטי:** קובץ `prices.json` מתעדכן ב-Repository, וכל משתמשי התוסף מקבלים אוטומטית את המחירים העדכניים דרך ה-CDN ללא צורך בהתקנה מחדש.

---

## 🔑 הגדרת מפתח ה-API ב-GitHub (חד-פעמי)

1. היכנס למאגר ה-GitHub של הפרויקט.
2. לחץ על **Settings** -> **Secrets and variables** -> **Actions**.
3. לחץ על כפתור **New repository secret**.
4. בשם הסוד (Name) הזן: `GEMINI_API_KEY`
5. בערך (Secret) הדבק את מפתח ה-API שלך מ-Google AI Studio.
6. שמור בלחיצה על **Add secret**.

## 💻 הרצה ידנית מקומית (למפתחים)

```bash
# התקנת תלויות
npm install

# הרצת בדיקות יחידה
npm run test-units

# הרצת עדכון מחירים מלא (דורש GEMINI_API_KEY בסביבה)
export GEMINI_API_KEY="your-key-here"
node scripts/update_prices.mjs

# הרצת בדיקה ללא שמירה (Dry-run) על 2 פריטים ראשונים
node scripts/update_prices.mjs --dry-run --limit 2
```

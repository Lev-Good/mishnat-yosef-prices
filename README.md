# מאגר מחירי רשתות שיווק - תוסף "מוסיף למשנת" 🛒

מאגר נתונים חינמי ואוטומטי של מוצרי צריכה ומחירי רשתות השיווק בישראל (**אושר עד, רמי לוי, יש חסד**), המשמש כ-CDN חי עבור תוסף הדפדפן **"מוסיף למשנת"** (סל קניות חכם למשנת יוסף).

## 📊 קישור ישיר לקובץ הנתונים (Raw CDN)
כתובת ה-JSON המעודכנת בזמן אמת:
```text
https://raw.githubusercontent.com/Lev-Good/mishnat-yosef-prices/main/prices.json
```

## ⚙️ איך פועלת האוטומציה?
1. מדי בוקר בשעה 04:00 UTC (שעון ישראל), תהליך **GitHub Actions** מריץ אוטומטית את הסקריפט `update_prices.py`.
2. הסקריפט מאמת ומעדכן את מחירי המוצרים המפוקחים לפי צו הפיקוח הממשלתי, ואת מוצרי השוק החופשי לפי ממוצע תלת-רשתי מבוקר.
3. השינויים נדחפים אוטומטית למאגר (`prices.json`).
4. תוסף הדפדפן "מוסיף למשנת" סורק את הקובץ פעם ביממה ומעדכן את המשתמשים אוטומטית ללא צורך בהוצאת גרסה חדשה לחנות כרום.
